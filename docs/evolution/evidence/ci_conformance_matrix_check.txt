### Engine Definitions
- **Wysna Seed Interpreter (`runtime/Interpreter.py`):** Canonical reference AST tree-walking interpreter.
- **Wysna Seed AST C99 (`codegen/CCodeGen.py`):** Secondary C99 oracle for differential validation.
- **Wysna Seed Typed HIR (`hir/HirCCodeGen.py`):** Primary compiler entry; verified MIR drives C99 emission (ADR-018).
- **Wysna Compiler Self-Hosted (`selfhost/compiler.wysna`):** Native Stage-2 compiler binary compiled via 3-stage bootstrap fixed-point.
