# Wysna 0.5.0

Wysna 0.5.0 is a pre-1.0 release of the Wysna programming language, Seed compiler,
standard library, project tools, and graphical installers.

## Installers

- **Windows x64:** per-user graphical `.exe` installer and portable `.zip`.
- **macOS arm64:** graphical `.pkg` installer.
- **Linux x64:** `.deb` and `.rpm` packages.

Download the installer for your operating system from the assets below. The release
contains platform installer manifests, individual provenance records, and a complete
`SHA256SUMS` file.

## Security and support status

The installers are **unsigned**. The macOS package is **not notarized**. Windows,
macOS, and Linux may show security prompts. Wysna 0.5.0 is pre-1.0; read the
[documented scope](https://github.com/WashingtonYandun/Wysna/blob/main/docs/SCOPE.md)
before using it for critical work.
