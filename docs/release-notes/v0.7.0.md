# Wysna 0.7.0

Wysna 0.7.0 is a pre-1.0 release of the Wysna programming language, Seed compiler,
Selfhost native toolchain, standard library, project workflows, and graphical installers.

## Highlights

- **Unified 8-Byte `WVal` ABI v3 & Lock-Free Atomic ARC + CoW:** Single NaN-boxed
  representation across C99, Seed AST/HIR/MIR, Selfhost Stage-2, and experimental LLVM,
  with `<=6B` SSO strings, opt-in Bacon-Rajan cycle collection (`WYSNA_COLLECT_CYCLES=1`),
  and thread-safe copy-on-write scalar lists.
- **Stackless CPS `async fn` & OS Concurrency:** Cooperative CPS state-machine lowering
  across Seed C99, LLVM, and Selfhost alongside OS worker pools (`std/algorithms.parallel_*`,
  `std/async.spawn`) and multiplexed HTTP (`curl_multi`).
- **Selfhost OOP Generics, Agent-First Native CLI & Stage-3 LSP:** Constrained generic classes
  and methods, `from ... use` imports, compiled C99 sandbox guards (`--sandbox`), hash-verified
  atomic CLI/MCP writes, Python-free Stage-3 LSP (`wysna lsp`), shared CLI/WebAssembly validation,
  and SQLite-backed service/browser pilot workflows.

## Installers

- **Windows x64:** per-user graphical `.exe` installer and portable `.zip`.
- **macOS arm64:** graphical `.pkg` installer.
- **Linux x64:** `.deb` and `.rpm` packages.

Download the installer for your operating system from the assets below. The release
contains platform installer manifests, individual provenance records, and a complete
`SHA256SUMS` file.

## Security and support status

The installers are **unsigned**. The macOS package is **not notarized**. Windows,
macOS, and Linux may show security prompts. Wysna 0.7.0 is pre-1.0; read the
[documented scope](https://github.com/WashingtonYandun/Wysna/blob/main/docs/SCOPE.md)
before using it for critical work.
