# Wysna 1.0.0

Wysna 1.0.0 is the first stable release of the Wysna programming language and toolchain (`package.language = "1.0"`, `toolchain.compiler = "1.0.0"`).

Documentation & Handbook: [https://wysna.wysofia.com/](https://wysna.wysofia.com/)

## Highlights

- **Deterministic Self-Hosted Native Compiler:** Verified 3-stage bootstrap fixed point (`C0 == C1 == C2`) compiling statically typed Wysna (`HIR`/`MIR`, ARC + copy-on-write values, contracts, typed errors, generics, async/await) to portable ANSI C99 with bundled Zig — zero Python runtime required in the Native SDK.
- **Agent-First Protocol & 13-Tool MCP Server:** Machine-readable `json-v1` diagnostics with multi-error recovery, canonical symbol identity (`inspect`, `graph`, `schema`, `api`, `fix`), atomic multi-file `workspace patch`, and checked architecture contracts (`wysna.toml` policies + `W6101`/`W6102`).
- **Offline Reproducible Projects & Packages:** Deterministic `wysna.toml` / `wysna.lock` workflows (`project check|build|run|test --frozen`) and SHA-256-pinned offline USTAR package archives.
- **Lossless CI & Automated Release Pipeline:** Shared C99 runtime object cache, verified bootstrap artifact reuse, sharded ASan+UBSan suites, branch-driven SemVer release automation (`develop` -> `release/*` -> `main`), and automatic synchronization with [wysna.wysofia.com](https://wysna.wysofia.com/).

## Distribution

Python-free Native SDK (with bundled Zig for `native-core-v1`):

- Windows x64: `wysna-1.0.0-native-x86_64-windows.zip`
- macOS arm64: `wysna-1.0.0-native-aarch64-macos.tar.gz`
- Linux x64: `wysna-1.0.0-native-x86_64-linux.tar.gz`

Seed installers bundle CPython and Zig in `.exe`, `.pkg`, `.deb`, and `.rpm` packages with manifests, provenance, and `SHA256SUMS`. Installers remain unsigned/unnotarized; verify checksums and provenance before installing.
