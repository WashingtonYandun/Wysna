# Wysna 0.8.0

Wysna 0.8.0 is a pre-1.0 release delivering full Python-free autonomy in the native SDK (`wysna project`, `wysna api`, and all 11 static MCP tools), parameterized generic interfaces in Selfhost, an 8x Selfhost MIR temporary-scope CoW speedup, multi-OS LLVM smoke coverage, and a real dogfooding application (`examples/wysofia-ops/`).

## Highlights

- **Full Standalone Native SDK Autonomy (Zero Python):** Added native `wysna.toml` v1 project workflows (`wysna project check|build|run|test`), native `wysna api` (`wysna.api-index/1`), and all 11 static tools in the stdio MCP server (`wysna mcp`), joining `schema`, `fix`, `skills`, `capabilities`, `graph`, `inspect`, `patch`, `explain`, `fmt`, and Stage-3 `lsp`.
- **Selfhost Constrained Parameterized Interfaces & 8x Bootstrap Speedup:** Added parameterized `interface Name[T]` / `implements` in Selfhost and tightened MIR temporary scopes around `if` conditions, `let` initializers, non-tail expression statements, `and`/`or` short-circuit branches, and direct ranges across both Seed and Selfhost (cutting quadratic CoW detaches so the expanded 33-module / 15,795-line Selfhost `--check` runs in ~5.51s on Apple Silicon).
- **LLVM Multi-OS Smoke CI & Real Dogfooding:** Expanded `llvm-smoke` CI coverage across `ubuntu-latest` and `macos-latest`, recorded Darwin arm64 `release` C99 vs LLVM benchmark measurements in `docs/LLVM_EXPERIMENTAL.md`, and shipped `examples/wysofia-ops/` (operational JSON/SQLite audit CLI with design-by-contract and FFI).

The installers are **unsigned**. The macOS package is **not notarized**. Windows,
macOS, and Linux may show security prompts. Wysna 0.8.0 is pre-1.0; read the
[documented scope](https://github.com/WashingtonYandun/Wysna/blob/main/docs/SCOPE.md)
before using it for critical work.
