# Wysna 0.8.0

Wysna 0.8.0 es una versión anterior a 1.0 que completa los flujos de proyectos del SDK nativo, amplía la paridad de genéricos y errores tipados y entrega una aplicación operativa de referencia. El SDK ejecuta su perfil `native-core-v1` sin Python; Seed conserva su implementación en Python y ofrece destinos y modos adicionales.

## Cambios principales

- **SDK nativo para proyectos:** `wysna project new|lock|check|build|run|test`, manifiestos `wysna.toml`, dependencias locales y lockfiles reproducibles. Se incluyen `wysna api`, las 11 herramientas MCP y LSP nativo, además de los comandos de inspección, edición y diagnóstico.
- **Genéricos y errores tipados:** interfaces parametrizadas, métodos genéricos y alternativas de error como `Failure[int] | Failure[str]` en Selfhost. Las especializaciones conservan su identidad en patrones y propagación; una unión inválida tras sustituir parámetros se rechaza antes de MIR. Hay regresiones específicas para reexportaciones, métodos y funciones `async`.
- **Ergonomía y memoria:** mejoras de literales, inferencia contextual, tuplas, actualización de structs y autofixes, junto con ámbitos temporales MIR que evitan copias CoW innecesarias. C99 continúa como backend estable y se mantiene la ABI v3 `WVal`.
- **Contratos host completos:** los 49 símbolos expuestos tienen entrada de efectos y comprobación de aridad Python/C. Se preservan los límites de confianza FFI y se verifica el préstamo y cierre de buffers de resolución de rutas.
- **Aplicación de referencia:** `examples/wysofia-ops/` incluye ingesta de archivos JSON, validación del lote, transformación y persistencia, además de la integración SQLite. Los lotes rechazados conservan el reporte anterior; no se promete escritura atómica ante una interrupción durante `write_file`.
- **Evaluación reproducible:** checkpoints por tarea, reanudación estricta, artefactos por intento y restricciones gratuitas de OpenRouter. No se presenta la validación con mocks como una medición de calidad de modelos; las campañas reales continúan aplazadas.
- **Distribución y backends:** aceptación instalada en Windows, macOS y Linux y pruebas LLVM explícitas en Linux/macOS. La independencia de Python del SDK se verifica con herramientas empaquetadas y PATH aislado.

## SDK nativo para proyectos C99

Descarga el archivo de tu plataforma y extráelo en un directorio nuevo. Ejecuta
`bin/wysna --version` en macOS y Linux, o abre `open-terminal.cmd` en Windows.

| Plataforma | Archivo |
| --- | --- |
| Windows x64 | `wysna-0.8.0-native-x86_64-windows.zip` |
| macOS arm64 | `wysna-0.8.0-native-aarch64-macos.tar.gz` |
| Linux x64 | `wysna-0.8.0-native-x86_64-linux.tar.gz` |

Cada archivo incluye Zig y se valida con `wysofia-ops` fuera del repositorio
y con Python fuera del PATH. `SHA256SUMS` incluye su huella SHA-256.

## Instaladores de Seed

- **Windows x64:** instalador gráfico `.exe` por usuario y archivo portable `.zip`.
- **macOS arm64:** instalador gráfico `.pkg`.
- **Linux x64:** paquetes `.deb` y `.rpm`.

Los archivos de esta release incluyen manifiestos de instalación, procedencia por plataforma y el inventario `SHA256SUMS`.
