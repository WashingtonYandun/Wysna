# Wysna 0.9.5

Wysna 0.9.5 builds on the 0.9 language and hybrid architecture with major runtime/compiler performance optimizations and two complete waves of Agent-First protocol, semantic graph, workspace patching, and MCP improvements — without breaking `0.9` manifest/syntax compatibility.

Documentation & Handbook: [https://wysna.wysofia.com/](https://wysna.wysofia.com/)

## Highlights

- **Agent-First Symbol Identity & Bounded Context (`#194`):** Declaration-level disambiguation with `[W1005]` candidates, `--max-bytes` bounded `inspect` with resumable `omitted[].ref` handles, and `call_resolution` / `analysis_boundaries` (`virtual-dispatch`, `indirect-call`, `c-ffi`) across Seed, Selfhost, and MCP.
- **Selfhost Multi-Error Recovery & Structured Diagnostics (`#195`):** Selfhost collects up to 100 unique errors with `error_type` cascade suppression and emits typed `data` + `related` declaration spans for `W1002`, `W2001`, `W2002`, `W2003`, `W2004`, `W2005`, and `W3001`, validated against strict `schemas/wysna-tool-result.v1.schema.json`.
- **Batch Inspect, Advanced Multi-File Workspace Patch & 13-Tool MCP (`#195`):** Adds `--symbols` / MCP `symbols` batch inspection, atomic multi-file edits (`source`, `symbol`, `hunks`, `create`, `delete`) with rollback in Native SDK + MCP, and `wysna_project_check` + opt-in `wysna_project_test --allow-exec`.
- **Performance Campaign (`#190`–`#193`):** Native C99 JSON extractors and quoting, ARC/ABI hotpath inlining, 2-buffer stable sort, MIR read-clone elision, dead-function tree-shaking, hoisted/borrowed `for`-loops, and O(1)/indexed compiler signature & import handling.

## Compatibility

Existing `0.9.0` code requires no syntax changes. Update `toolchain.compiler` to `"0.9.5"` in `wysna.toml` (keeping `language = "0.9"`) and refresh locks with `wysna project lock` before running `--frozen`. For projects still on `0.8`, follow [Migration 0.8 → 0.9](https://github.com/WashingtonYandun/Wysna/blob/{{SOURCE_COMMIT}}/docs/MIGRATING_0_8_TO_0_9.md).

## Distribution

Python-free Native SDK (with bundled Zig for `native-core-v1`):

- Windows x64: `wysna-0.9.5-native-x86_64-windows.zip`
- macOS arm64: `wysna-0.9.5-native-aarch64-macos.tar.gz`
- Linux x64: `wysna-0.9.5-native-x86_64-linux.tar.gz`

Seed installers bundle CPython and Zig in `.exe`, `.pkg`, `.deb`, and `.rpm` packages with manifests, provenance, and `SHA256SUMS`. Installers remain unsigned/unnotarized; verify checksums and provenance before installing.
